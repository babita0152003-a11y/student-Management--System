# student-Management--System
Python project for managing student records
Student Management System

Project Description

Student Management System is a beginner-friendly Python project designed to manage student records.

Technologies Used

- Python
- Visual Studio Code

Features

- Add Student
- View Students
- Search Student
- Exit the Program

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python main.py

Learning Outcomes

- Python basics
- Variables and input
- If-else statements
- Loops
- Lists and Dictionaries
